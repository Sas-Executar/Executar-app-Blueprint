# Env Mapping

Mapeamento entre variáveis de ambiente/configuração exigidas pelas specs
deste repositório e as variáveis já existentes na plataforma
`Sas-Executar/next-forge`.

| SPEC (necessidade proprietária) | NEXT-FORGE ENV VAR | STATUS |
|---|---|---|
| _(nenhuma necessidade de configuração foi ingerida ainda)_ | | |

Este arquivo é preenchido apenas quando uma capability real declarar uma
dependência de configuração (ex.: um provider de integração em
`70-INTEGRATIONS/providers`) — nenhum valor deve ser inventado
antecipadamente, e nenhum segredo ou valor real deve ser registrado aqui.
