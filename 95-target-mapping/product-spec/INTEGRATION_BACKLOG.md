# Integration Backlog

Backlog inicial dos itens de integração pendentes entre este repositório e
`Sas-Executar/next-forge`. Estruturado, porém vazio — nenhum item foi
inventado. Populado conforme os mapeamentos em `NEXT_FORGE_MAPPING.md`
amadurecem de `NOT STARTED`/`NOT MAPPED` para um item acionável real.

## Schema

| Campo | Descrição |
|---|---|
| `ITEM` | Descrição curta do item de integração. |
| `CAPABILITY` | `CAPABILITY_ID` relacionado (`00-MANIFEST/CAPABILITY_MAP.md`). |
| `TARGET` | Pacote/app do next-forge afetado. |
| `ACTION` | `CONFIGURE` / `ADAPT` / `EXTEND` / `GENERATE` / `IMPLEMENT`. |
| `STATUS` | `BACKLOG` / `READY` / `IN PROGRESS` / `DONE`. |
| `PRIORITY` | `P0` / `P1` / `P2`. |
